# Cuenca Neuquina — versión 2.0

Versión renovada de la web académica sobre la Cuenca Neuquina y Vaca Muerta.

## Qué incluye
- Diseño responsive de nivel editorial/ingeniería.
- Mapa interactivo con IGN Argenmap y vista satelital.
- Línea de tiempo geológica interactiva.
- Corte conceptual del subsuelo y pozo horizontal animado.
- Explicación del sistema petrolero y propiedades de roca.
- Proceso de perforación/completación/estimulación/producción.
- Laboratorio virtual didáctico.
- Indicadores actualizados a 2026.
- Quiz de 8 preguntas.
- Fuentes oficiales enlazadas.

## Publicación en GitHub Pages
Reemplazá los archivos del repositorio por los de esta carpeta y mantené `index.html` en la raíz.

## Importante
Los mapas y cortes del subsuelo son esquemáticos con fines educativos. Los datos de 2026 incluyen su fecha y fuente en la sección "Indicadores 2026".
